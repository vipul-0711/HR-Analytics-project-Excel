📊 ADECCO HR Analytics Dashboard (Excel)
📌 Project Overview

The ADECCO HR Analytics Dashboard is an interactive Microsoft Excel dashboard designed to analyze employee data and provide actionable HR insights. The dashboard helps HR professionals monitor workforce trends, employee attrition, demographics, and job-related metrics using Pivot Tables, Pivot Charts, KPI Cards, and Slicers.

🎯 Project Objectives
Monitor employee attrition and workforce distribution.
Analyze employee demographics and job roles.
Identify departments with high attrition.
Track overtime and employee satisfaction.

Create an interactive dashboard for HR decision-making.
🛠️ Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
KPI Cards
Slicers
Conditional Formatting
Excel Formulas (COUNTIF, AVERAGE, COUNTA, etc.)
📊 Dashboard KPIs
KPI	Description
👥 Total Employees	Total number of employees
❌ Employees Left	Number of employees who left
📉 Attrition Rate	Percentage of employee attrition
👤 Average Age	Average employee age
💰 Average Monthly Income	Average monthly salary
📅 Average Tenure	Average years at the company
😊 Average Job Satisfaction	Average employee satisfaction score
⏰ Overtime Employees	Employees working overtime
📈 Dashboard Visualizations
📊 Attrition by Department (Bar Chart)
🥧 Employees by Gender (Pie Chart)
📊 Attrition by Job Role (Bar Chart)
📈 Overtime vs Attrition (Column Chart)
📊 Employees by Education Field (Bar Chart)
📈 Employees by Job Satisfaction (Column Chart)
